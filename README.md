# AJ Launcher

مشروع Android Launcher أصلي باسم AJ Launcher، يستهدف Android 13 وما فوق.

## مواصفات النسخة الأولية

- الحد الأدنى Android 13 / API 33.
- شاشة رئيسية بديلة يمكن تعيينها من إعدادات Home في الهاتف.
- عرض التطبيقات المثبتة التي تملك أيقونة تشغيل.
- الإعدادات الافتراضية المعتمدة: أيقونات 42dp، شكل مستدير، 5 أعمدة، مسافة 2، وأسماء التطبيقات ظاهرة.
- تبديل المظهر بين العصري والبسيط.
- تغيير حجم الأيقونات وعدد الأعمدة وشكلها والمسافات وإظهار الأسماء.
- ساعة وتاريخ رقميان مع إظهار/إخفاء التاريخ والثواني وتغيير اللون وتنسيق 12/24 ساعة.
- اختيار صورة ثابتة أو صورة GIF متحركة أو فيديو كخلفية.
- كتم صوت فيديو الخلفية افتراضياً، مع خيار تشغيل الصوت.
- سحب الأيقونات وإفلاتها فوق تطبيق آخر لتغيير ترتيبها.

## البناء السحابي

يحتوي المستودع على GitHub Actions في `.github/workflows/build-apk.yml`.
بعد رفع المشروع إلى مستودع GitHub جديد على الفرع `main` أو `master`:

1. افتح تبويب **Actions**.
2. اختر **Build AJ Launcher APK**.
3. عند أول رفع يبدأ البناء تلقائياً، ويمكن أيضاً تشغيله من **Run workflow**.
4. عند نجاح البناء افتح نتيجة التشغيل ونزّل الملف من قسم **Artifacts** باسم `AJ-Launcher-debug-APK`.
5. فك ضغط الأرشيف، وستجد `app-debug.apk`.

## تنبيه

هذه نسخة تأسيسية أولى. يجب أن ينجح بناء GitHub Actions ثم تثبيت APK وتجربته على هاتف Android 13 فعلياً قبل اعتبارها إصداراً جاهزاً. بناء Debug مخصص للاختبار، وليس إصداراً موقعاً للنشر في المتجر.
